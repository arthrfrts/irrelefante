# Irrelefante

Meu blog/diário/jardim digital na internet, disponível no <irrelefante.com.br/>. Minha ideia é tornar esse site meu repositório de tudo o que eu já escrevi, passando pelo [Um filme por dia][filmedodia], [Pão com Mortadela][pcm], no Tumblr, até chegar nos dias de hoje.

Feito com [Jekyll][jekyll], que pega os arquivos Markdown em `_posts` e os transforma em um site, sem banco de dados e sem problemas. Tentando seguir os princípios da [IndieWeb][iwc], como [webmentions][jwb] e [microformats][mf2].
